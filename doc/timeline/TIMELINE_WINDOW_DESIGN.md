# ZEngine TimelineWindow 设计文档

## 概述

TimelineWindow是ZEngine编辑器中的时间轴编辑窗口，参考了Unity Timeline和Unreal Engine的Sequence系统设计。它提供了一个直观的可视化界面，用于编辑Timeline资源，包括轨道管理、片段编辑、播放控制等功能。

## 设计目标

1. **直观的可视化编辑**：提供类似Unity Timeline和UE Sequence的直观界面
2. **完整的编辑功能**：支持轨道的添加、删除、复制，片段的创建、编辑、删除、拖拽等
3. **精确的时间控制**：支持帧对齐、时间缩放、播放控制等
4. **灵活的交互方式**：支持多种编辑模式（选择、移动、修剪、分割）

## 核心功能

### 1. 播放控制栏（Toolbar）

位于窗口顶部，包含：
- **播放控制按钮**：播放（>）、暂停（||）、停止（[]）
- **时间显示**：显示当前播放时间（秒）和帧数
- **播放速度控制**：可调节播放速度（0.1x - 10x）
- **循环播放开关**：控制是否循环播放
- **帧对齐开关**：控制是否对齐到帧
- **片段对齐开关**：控制是否对齐到其他片段
- **缩放控制**：调整时间轴的缩放级别（像素/秒）
- **编辑模式选择**：选择当前编辑模式（选择、移动、修剪、分割）

### 2. 轨道列表（Track List）

位于窗口左侧，显示所有轨道：
- **轨道树形视图**：以树形结构显示所有轨道
- **轨道属性**：显示轨道类型、片段数量等信息
- **轨道操作**：右键菜单支持删除、复制、启用/禁用、锁定、静音等操作
- **添加轨道按钮**：支持添加不同类型的轨道（动画、激活、音频、事件）

### 3. 时间轴视图（Timeline View）

位于窗口右侧，显示时间轴和片段：
- **时间标尺**：显示时间刻度（秒和帧）
- **轨道时间轴**：每个轨道对应一行，显示该轨道上的所有片段
- **片段可视化**：以彩色矩形显示片段，不同颜色表示不同类型
- **当前时间指示器**：红色竖线显示当前播放位置
- **片段交互**：支持点击选择、拖拽移动、调整大小等操作

### 4. 片段编辑功能

- **选择**：点击片段进行选择，支持单选和多选
- **移动**：拖拽片段改变其开始时间
- **修剪**：拖拽片段边缘调整其持续时间
- **分割**：在指定时间点分割片段
- **复制**：复制选中的片段
- **删除**：删除选中的片段

### 5. 轨道管理功能

- **添加轨道**：支持添加动画、激活、音频、事件四种类型的轨道
- **删除轨道**：删除选中的轨道及其所有片段
- **复制轨道**：复制轨道及其所有片段
- **移动轨道**：调整轨道顺序
- **轨道属性**：设置轨道名称、启用状态、锁定状态、静音状态等

## 数据结构

### TimelineWindow类

主要成员变量：
- `m_current_asset`: 当前编辑的Timeline资源
- `m_play_state`: 播放状态（停止、播放、暂停）
- `m_current_time`: 当前播放时间
- `m_play_speed`: 播放速度
- `m_edit_mode`: 编辑模式
- `m_selected_clip`: 选中的片段
- `m_pixels_per_second`: 缩放级别（每秒像素数）
- `m_time_range_start/end`: 可见时间范围

### 关键方法

- `setTimelineAsset()`: 设置当前编辑的Timeline资源
- `play()/pause()/stop()`: 播放控制
- `addTrack()/deleteTrack()`: 轨道管理
- `addClip()/deleteClip()`: 片段管理
- `onClipMoved()/onClipTrimmed()`: 片段编辑
- `renderToolbar()/renderTrackList()/renderTimelineView()`: UI渲染

## 颜色方案

### 轨道颜色

- **动画轨道**: 蓝色 (100, 150, 255)
- **激活轨道**: 紫色 (150, 100, 255)
- **音频轨道**: 橙色 (255, 150, 100)
- **事件轨道**: 绿色 (100, 255, 150)

### 片段颜色

- 使用与轨道相同的颜色，但更不透明
- 选中时显示为黄色

## 时间轴特性

### 帧对齐

- 支持对齐到帧，确保片段边界精确对齐到帧边界
- 可通过工具栏开关控制

### 片段对齐

- 支持对齐到其他片段，方便精确对齐
- 可通过工具栏开关控制

### 缩放

- 支持时间轴缩放，调整可见时间范围
- 缩放级别：10-1000 像素/秒
- 可通过工具栏滑块控制
